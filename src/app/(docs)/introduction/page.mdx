# Introduction

**Chatty** is an enterprise AI chatbot and agent orchestration platform. Build, train, and deploy intelligent conversational assistants for your website, web app, WhatsApp, Slack, or mobile applications — backed by custom knowledge, real-time calendar scheduling, and live human takeover.

The **Chatty Developer Platform** gives you full programmatic access: stream tokens via Server-Sent Events (SSE), ingest multimodal files and voice notes, manage knowledge vectors, automate meetings, and operate bots using autonomous AI coding agents via the Model Context Protocol (MCP).

## Base API URL

All public and developer API requests are served over TLS 1.3:

```
https://api.chatty.personaliai.com
```

---

## Quick Example (Streaming SSE)

```bash
curl -N -X POST https://api.chatty.personaliai.com/api/widget/chat/stream \
  -H "Authorization: Bearer YOUR_BOT_ID" \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{
    "text": "What enterprise features do you offer?",
    "visitor_timezone": "America/New_York"
  }'
```

```
event: token
data: {"token": "We provide"}

event: token
data: {"token": " custom domain allowlisting, SSO, RAG sync, and human takeover."}

event: done
data: {"session_id": "1fa85f64-5717-4562-b3fc-2c963f66afa6"}
```
