# Model Context Protocol (MCP) Server

Chatty provides a first-class [Model Context Protocol (MCP)](https://modelcontextprotocol.io) server. With MCP, autonomous AI agents inside **Claude Desktop**, **Cursor IDE**, **Claude Code**, or **Windsurf** can inspect, configure, train, and monitor your entire chatbot fleet using natural conversation.

---

## The 8 Core MCP Tool Suites

Chatty exposes 8 dedicated tool suites through its streamable HTTP MCP interface:

<AccordionGroup>
  <Accordion title="1. Bot Lifecycle Suite">
    - `list_chatbots`: List all bots on your account with IDs, names, models, and status.
    - `create_chatbot`: Spin up a new bot with custom system prompts, welcome messages, and initial settings.
    - `get_chatbot`: Retrieve detailed parameters for a specific bot UUID.
    - `update_chatbot`: Modify temperature, LLM model choice (Gemini 2.5 Pro/Flash, GPT-4o), or system guardrails.
    - `delete_chatbot`: Decommission and archive a bot instance.
  </Accordion>

  <Accordion title="2. Knowledge & Vector RAG Suite">
    - `list_chatbot_knowledge`: Enumerate indexed documents, crawled URLs, and manual text snippets.
    - `add_chatbot_knowledge`: Ingest new text blocks, documentation URLs, or file URLs into vector embeddings.
    - `delete_chatbot_knowledge`: Purge outdated knowledge sources from the pgvector database.
    - `sync_knowledge_source`: Trigger an immediate re-index of connected Google Drive folders or sitemaps.
  </Accordion>

  <Accordion title="3. Styling & Theme Engine Suite">
    - `get_chatbot_theme`: Inspect widget styling, brand colors, typography, and launcher icon settings.
    - `update_chatbot_theme`: Update primary colors, dark/light theme defaults, launcher positions, or custom CSS rules.
  </Accordion>

  <Accordion title="4. Visual Flow & Decision Trees Suite">
    - `get_visual_flow`: Fetch the structured visual decision tree and multi-branch logic for conversational flows.
    - `update_visual_flow`: Programmatically modify conversation paths, question nodes, and branch logic.
  </Accordion>

  <Accordion title="5. Campaigns & Proactive Triggers Suite">
    - `list_campaigns`: View active trigger campaigns, delay timers, and URL matching patterns.
    - `create_campaign`: Set up proactive popup notifications for high-intent pages (e.g. pricing or cart checkout).
  </Accordion>

  <Accordion title="6. Voice & Multimodal Settings Suite">
    - `get_voice_settings`: Inspect speech synthesis preferences, ElevenLabs voice IDs, and audio speed.
    - `update_voice_settings`: Toggle voice input/transcription options and adjust speech recognition models.
  </Accordion>

  <Accordion title="7. Live Inbox & Human Takeover Suite">
    - `list_active_conversations`: Enumerate open visitor threads, unread counts, and escalation flags.
    - `send_agent_message`: Transmit a human operator reply directly into a live chat session.
    - `pause_ai_stream`: Set `ai_paused: true` to prevent the bot from responding while an agent handles the user.
    - `resume_ai_stream`: Restore automated AI responses for the thread.
  </Accordion>

  <Accordion title="8. Security & Analytics Suite">
    - `analyze_chatbot`: Aggregate total conversations, message counts, resolved tickets, and CSAT scores.
    - `audit_security_settings`: Verify domain allowlists, rate limiting configurations, and public token status.
    - `export_bot_logs`: Download audit trails and conversation transcripts for compliance reviews.
  </Accordion>
</AccordionGroup>

## Client Configuration

Chatty's MCP endpoint is hosted at:
```
https://api.chatty.personaliai.com/mcp
```

### 1. Claude Desktop Setup

Edit your Claude Desktop configuration file:
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "chatty": {
      "url": "https://api.chatty.personaliai.com/mcp"
    }
  }
}
```

### 2. Cursor IDE Setup

In your project root, create or edit `.cursor/mcp.json`:

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "chatty": {
      "url": "https://api.chatty.personaliai.com/mcp",
      "headers": {
        "Authorization": "Bearer chatty_sk_your_api_key_here"
      }
    }
  }
}
```

### 3. Claude Code CLI

Add the server directly from your terminal:

```bash title="Terminal"
claude mcp add chatty https://api.chatty.personaliai.com/mcp
```

## Authentication & OAuth2 Handshake

When using Claude Desktop or other dynamic clients, Chatty supports RFC 7591 Dynamic Client Registration and OAuth2 Discovery:

1. The MCP client queries `/.well-known/oauth-protected-resource/mcp`.
2. The client registers automatically and opens your browser to the Chatty authorization screen.
3. You approve the connection with your Chatty account credentials.
4. The client receives a scoped OAuth2 token and begins interacting with your bots.

<Tip>
When using developer environments like Cursor or headless CI/CD pipelines, you can pass a standard API Key (`chatty_sk_...`) in the `Authorization: Bearer` header to bypass the interactive browser login.
</Tip>
