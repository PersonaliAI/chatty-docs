## Live Presence & Auto-Assignment

Agents can toggle their status between **Online**, **Busy**, and **Offline** from the dashboard header:

- **Round-Robin Auto-Dispatch**: Automatically balances incoming visitor tickets across all currently Online agents with available capacity.
- **First Response SLA**: Monitors ticket wait time and triggers escalation alerts if an incoming conversation is not claimed within the defined SLA window.
- **Unassign & Reassign**: Reassign tickets seamlessly between agents or return them to the unassigned queue for dispatch.
